# Dayline Android MVP

Timeline-first memo app prototype for Android.

## Included
- Horizontal date timeline
- Date-based notes
- Checklist notes with progress
- Simple mind-map notes
- Local auto-organize helpers
- Offline bundled web assets
- On-device storage using WebView localStorage

## Build APK on GitHub
Push this project to a GitHub repository. The included workflow `.github/workflows/build-apk.yml` builds a debug APK automatically on pushes to `main`, and can also be started manually from **Actions > Build Dayline APK > Run workflow**.

When the workflow completes, download the **Dayline-APK** artifact. It contains `Dayline-debug.apk`.
